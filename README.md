# TWO SIDES — Duo Escape [2 PLAYER]

Кооперативная головоломка для Roblox на двоих. Игроки находятся в одном здании, но в двух
параллельных мирах — **светлом** и **тёмном**. Видят друг друга как призраков, а пройти
комнату можно, только договорившись: плита одного открывает дверь другому, ящик одного
становится ступенькой для другого, код видит один — вводит другой.

> Статус: **этап 2 — контент MVP** (лобби, подбор пары, два мира, 8 механик, 5 комнат, свои иконки).
> План — [`docs/PLAN.md`](docs/PLAN.md), экономика — [`docs/ECONOMY.md`](docs/ECONOMY.md).

## Как запустить (5 минут)

Код живёт в этом репозитории, а в Studio его «приносит» **Rojo**.

### 1. Установить инструменты (один раз)

1. **Roblox Studio** — https://create.roblox.com
2. **Rokit** (менеджер инструментов) — скачать со страницы релизов
   `github.com/rojo-rbx/rokit/releases` и установить.
3. В папке проекта выполнить:

```bash
rokit install
```

   Это поставит `rojo`, `selene`, `stylua` нужных версий (см. `rokit.toml`).

4. Плагин Rojo для Studio:

```bash
rojo plugin install
```

5. (Рекомендуется) **VS Code** + расширения *Rojo*, *Luau Language Server*, *Selene*, *StyLua*.

### 2. Запуск

**Вариант А — живая синхронизация (для разработки):**

```bash
rojo serve
```

Открыть в Studio пустой **Baseplate**, во вкладке *Plugins → Rojo* нажать **Connect**.
Любое сохранение файла в VS Code сразу появляется в Studio.

**Вариант Б — собрать файл места:**

```bash
rojo build -o TwoSides.rbxl
```

и открыть `TwoSides.rbxl` в Studio.

### 3. Как протестировать одному

Нажать ▶ **Play**. В лобби (только в Studio) есть розовая площадка **«Тест одному (Studio)»**.
Встать на неё — через 3 секунды вы в комнате 1. Клавиша **T** (или розовая кнопка справа)
переключает мир: так можно пройти комнату за обоих. В этом режиме плиты держатся
6 секунд после того, как с них сошли, — чтобы успеть переключиться и пройти.

Ошибки и сообщения скриптов — в окне **Output** (меню *View* или *Window* → *Output*).

### 4. Как протестировать вдвоём в Studio

*Test → Clients and Servers → 2 Players → Start.* Откроются два окна-клиента.
В каждом встаньте на одну и ту же площадку «Вдвоём с другом» — через 3 секунды вы в комнате 1.

Лобби строится кодом автоматически, если в Workspace нет папки `Lobby`.

## Архитектура

```
src/
├── shared/                 → ReplicatedStorage.Shared (сервер + клиент)
│   ├── Constants.luau      стороны, группы коллизий, имена атрибутов, цвета, список remote'ов
│   ├── Config.luau         числа для баланса (таймеры, дистанции)
│   ├── Net.luau            создание/получение RemoteEvent
│   ├── Signal.luau         простые события
│   └── Zone.luau           «точка внутри детали»
├── server/                 → ServerScriptService.Server
│   ├── init.server.luau    запуск сервисов (Init → Start)
│   ├── Services/
│   │   ├── CollisionService    группы коллизий двух миров
│   │   ├── WorldService        лобби и папка Sessions
│   │   ├── LobbyService        площадки подбора пары
│   │   └── SessionService      жизнь пары: стороны, комнаты, выход напарника, респавн
│   ├── Room/
│   │   ├── RoomKit             конструктор комнат из кода
│   │   ├── RoomRuntime         механики, связи, проверка зон
│   │   └── Mechanics/          Gate (двери/мосты), Plate, Lever, MirrorBox, Keypad, CodeDigit
│   └── Rooms/              список комнат главы и сами комнаты
└── client/                 → StarterPlayerScripts.Client
    ├── Controllers/
    │   ├── DimensionController скрывает чужой мир, призрак напарника, цвет мира
    │   ├── HudController       верхняя панель, подсказка, уведомления
    │   └── KeypadController    экран ввода кода
    └── Ui.luau             помощник для интерфейса
```

### Как устроены «два мира»

* У каждой детали комнаты есть атрибут **`Side`** = `Light` / `Dark` / `Shared`.
* **Физика** — группы коллизий: светлый игрок сталкивается только со светлыми и общими
  деталями, тёмный — с тёмными и общими. Игроки друг с другом не сталкиваются.
* **Картинка** — каждый клиент сам прячет детали чужого мира (`LocalTransparencyModifier`)
  и выключает их надписи, свет и подсказки. Напарник рисуется полупрозрачным призраком.
* **Логика** — на сервере. Он проверяет, что пользоваться рычагом или панелью может только
  игрок нужной стороны, и сам проверяет коды.

### Связи (Link)

Источники (плита, рычаг, кодовая панель) включают связь по имени, получатели (дверь, мост)
на неё реагируют. Связь активна, если активен хоть один источник.

| Mech | Что делает | Атрибуты |
|---|---|---|
| `Plate` | активна, пока на ней стоит игрок **или ящик** этой стороны | `Link` |
| `Lever` | переключатель (E / тап) | `Link` |
| `Keypad` | правильный код — связь включена навсегда | `Link`, `CodeGroup` |
| `CodeDigit` | показывает одну цифру кода с номером | `CodeGroup`, `CodeIndex` |
| `Door` | проход открыт, пока связь активна | `Link` |
| `Bridge` | твёрдый, пока связь активна | `Link` |
| `MirrorBox` | ящик + его «эхо» в другом мире | — |
| `Mover` | лифт / сдвижная стена: сдвинут на `MoveOffset`, пока связь активна | `Link`, `MoveOffset`, `MoveTime` |
| `AnomalyItem` | «найди отличие»: оба отмечают один предмет, где мир отличается | `AnomalyGroup`, `AnomalyIndex`, `Link` |
| `Spawn` | точка появления стороны | `SpawnSide` |
| `Exit` | оба игрока внутри — комната пройдена | — |
| `KillZone` | вернуть игрока на точку появления | — |

### Как добавить комнату

1. Скопировать `src/server/Rooms/Room01_TwoSides.luau`, поменять `Id`, `Name`, `Hints`, `Build`.
2. Вписать модуль в `src/server/Rooms/init.luau`.

Все размеры — в studs, `y = 0` — уровень пола, центр комнаты — `(0, 0, 0)`.
Позже комнаты можно будет собирать в Studio вручную, проставляя те же атрибуты.

## Иконки и картинки

Все картинки — свои, лежат в `assets/` и пересобираются скриптами из `tools/`.

| Файл | Что это |
|---|---|
| `assets/icons-sheet.png` | атлас из 19 иконок интерфейса (белые, красятся кодом) |
| `assets/icons/*.png` | те же иконки по отдельности, 256×256 |
| `assets/icons-preview.png` | все иконки на тёмном фоне — посмотреть |
| `assets/branding/game-icon-512.png` | иконка игры для страницы Roblox |
| `assets/branding/thumbnail-1920x1080.png` | превью для страницы игры |

**Подключить иконки в игре (один раз):**
1. В Studio: *View* (или *Window*) → **Asset Manager** → **Bulk Import** → выбрать `assets/icons-sheet.png`.
2. Правый клик по загруженной картинке → **Copy ID**.
3. Вставить в `src/shared/Icons.luau`: `Icons.SHEET_ID = "rbxassetid://ЧИСЛО"`.

Пока ID не вставлен, вместо иконок показываются символы — игра работает и так.

**Иконка и превью игры** загружаются на сайте: *Creator Dashboard → твоя игра → Configure
→ Places / Thumbnails*.

**Перерисовать иконки** (правка SVG в `tools/icons.html`):

```bash
node tools/render_icons.js && python3 tools/build_spritesheet.py
```
